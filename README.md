# Helping Hands

A student MYP Service as Action website featuring 29 trusted projects that fight child labour, poverty, hunger and lack of schooling. Each project links to its own official donation page.

**Live site:** https://virajsinghchadha.github.io/helping-hands/

Facts come from the [ILO](https://www.ilo.org/topics-and-sectors/child-labour) and the [World Bank](https://www.worldbank.org/en/topic/poverty/overview). This site is not run by or connected to any organization listed.
